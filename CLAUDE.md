# nary-upi

NestJS learning project: backend for a UPI expense tracker. Product spec in `plan/project-plan.md`, phase roadmap in `plan/phases.md` (both git-ignored).

## Workflow

- Build one phase at a time from `plan/phases.md`; stop after each phase so the owner can review and learn.
- After each phase, explain in detail what was done and which NestJS concepts it introduced.
- Keep code lean: no explanatory comments in source files; explanations go in the phase write-up.

- Author and committer: `Nary-Vip <nary2vip@gmail.com>` only.
- Subject line only: no description/body.
- No `Co-Authored-By` or any Claude/AI attribution.
- One commit per phase, made only after the owner approves.
